**PageProof — SEO Page Auditor**

A local auditor that uses TinyFish Search for query results/snippets, live Fetch for extractable text, and Browser CDP for rendered metadata. Findings include evidence, impact and specific fixes, plus HTML/JSON downloads.

The demo shows a fresh TinyFish documentation audit, saved live Example Domain/homepage receipts and separately labeled synthetic JSON-LD failure tests. Failed measurements remain not tested. The published scoring formula measures page hygiene; it makes no ranking or indexing claims.

Build: https://github.com/himanshu748/pageproof-seo-auditor
Demo: https://github.com/himanshu748/pageproof-seo-auditor/blob/codex/publication/seo-auditor/submission/PageProof-demo.mp4

30 automated tests; genuine redacted receipts included. Permitted public HTTPS pages only, server-side key, bounded approved credits, zero retries. No audited website was modified.
