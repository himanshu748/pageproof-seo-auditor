I built PageProof for the TinyBounties SEO Page Auditor challenge.

It compares three views of a permitted public page: TinyFish Search results, Fetch text extraction, and Browser rendered DOM. Each check shows evidence and a specific fix, with HTML and JSON exports.

The demo includes a fresh TinyFish audit and saved live receipts from several real pages. Example Domain needs a description and H1. A Search failure on the TinyFish homepage stays “not tested.” Synthetic failure fixtures are labeled separately.

The score is a published page-hygiene heuristic with measurement coverage. It makes no Google ranking, indexing or traffic claims.

Built with @TinyFish.
